# AngKorGit 中文版 v0.15.1

同步上游 v0.15.0，并包含 `b3faaf1` 的 Windows 文件定位修复。此次仅发布 Windows x64 中文安装包。

## 新增功能

- 从侧边栏添加远端，保存后立即获取其分支。
- 向上游仓库创建跨 Fork 拉取请求或合并请求，支持 GitHub、GitLab 与 Bitbucket Cloud。
- 在设置中选择默认克隆目录，并记住最近一次使用的克隆目录。
- 终端右键菜单支持复制、粘贴、全选与清空。

## 修复与改进

- Windows SSH 改用 OpenSSL 版 libssh2，支持 ed25519 与 ECDSA 主机密钥。
- Windows“在文件管理器中显示”正确打开目录并选中文件。
- 长行差异限制显示长度，但复制仍保留完整内容；优化水平滚动。
- 差异文本选区在滚动离开并返回后保持原位，支持复制屏幕外的选区。
- 合入 Linux Wayland 紧凑标题栏改进，供源码构建使用。

## 中文化

- 补齐新增远端、跨仓库 PR/MR、克隆目录、终端菜单和长行提示。
- 同步本地化错误消息、无障碍标签与测试选择器。
- 保留手工维护的中文内容、中文版更新地址及公钥。
- 更新开发说明、路线图、问题反馈模板与网站下载入口；不再把未提供的中文 DMG/AppImage 列为可下载产物。

## 安装与自动更新

- Windows NSIS：`AngKorGit_0.15.1_x64-setup.exe`。
- Windows MSI：`AngKorGit_0.15.1_x64_en-US.msi`；文件名中的 `en-US` 是安装器语言标识，应用界面为中文。
- 安装包没有商业代码签名证书，Windows SmartScreen 首次运行可能提示发布者未知。
- 应用内自动更新仍使用本仓库的 `latest.json` 与更新签名；更新签名不等同于商业代码签名。
- macOS/Linux 未发布中文安装包，可自行编译本仓库源码或下载未汉化的上游原版。

## 从源码构建

Windows 新增原生 Perl 构建依赖（推荐 Strawberry Perl 并加入 `PATH`），用于编译 OpenSSL。安装成品应用不需要 Perl。
